# root.narciso - Portafolio Personal

Repositorio del código fuente de mi portafolio profesional, diseñado para documentar y presentar proyectos de administración de sistemas Linux, redes y ciberseguridad.

## Arquitectura del Proyecto

* **Frontend:** Construido con Astro y Tailwind CSS v4, priorizando un rendimiento veloz, transiciones de vista nativas y diseño responsivo sin dependencias pesadas de JavaScript.
* **Despliegue Web:** Alojado en Vercel, conectado al dominio principal.
* **Infraestructura Backend (En desarrollo):** Microservicio REST de mensajería (contacto) construido en Python (FastAPI). Contenedorizado con Docker y servido desde un homelab en Raspberry Pi mediante Cloudflare Tunnels para evitar la exposición directa de puertos.

## Pila Tecnológica

* Astro
* Tailwind CSS v4
* JavaScript (Vanilla)
